# Datheon Generative AI Internship - Task 1

## Structured LLM Prompt Pipeline & JSON Extractor

### Overview
This project implements a structured data extraction pipeline using Python, the Google GenAI SDK, and Pydantic schemas. It converts unstructured raw text (resumes/documents) into strictly validated JSON outputs.

### Tech Stack
- Python 3.10+
- Google GenAI SDK (`gemini-3.5-flash-lite`)
- Pydantic v2
- python-dotenv
